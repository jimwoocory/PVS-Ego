# U2 媒体证据与 U4/U5 引用核验

2026-10-20。范围为独立隔离仓库的本地证据链。构建退出 0，唯一专项最终 **29 PASS / 0 FAIL**、套件退出 0；两个实际应用进程均退出 0。没有运行全量测试、外部模型或平台操作。

## 实现

- 新分析在请求前保存独立、不可变的采样清单 Artifact，绑定项目、源文件 ID/SHA、媒体信息、帧 Artifact/SHA、实际解码 PTS、采样限制和音轨观察状态。分析内容哈希同时包含清单引用。清单用于检测引用不一致，不是第三方签名或外部事实证明。
- 保存的源文件、帧和清单在使用时核对 READY、项目、MIME、字节数、SHA、实际路径及单链接普通文件。JPEG/视频另有文件头基础检查；这不代替完整格式解码或恶意媒体安全扫描。浏览器预览复用也核对原 Artifact。
- 模型图片直接来自已保存并核验的帧字节。请求前、响应后和保存分析前重新核对证据，避免把运行期间改变的媒体保存为有效分析。无帧、重复/越界/乱序 PTS 在请求前阻断。
- 缓存失效只阻断，不修改证据、不补造观察、不自动重新请求。旧分析继续保留；没有新采样清单的历史 v3 不能直接复用，需要另行明确重新分析。缺失音频观察不会因此升级。
- Creative、Script、Hermes Director 和 ProductDirectorService 默认接入异步核验：当前数据库 ACTIVE ID/版本/哈希与传入对象必须一致，文件与清单也必须有效。初次请求、事实纠正请求、响应及脚本/导演使用规则检查都受核验；带参考视频而未注入核验器时拒绝执行。无参考视频的原调用兼容。
- U4 原始评论页对照增加正文逐项验证。原始正文缺失或与归一化正文不同即阻断；已有账号、作品、父评论、游标检查保留。未观察计数仍 UNKNOWN，终页仍不代表全平台覆盖；缺失原始关系仍按已有规则保留未知，不强行升级为已证实关系。
- U5 冻结证据增加重复引用、引用类型、样本数量、观察时间窗和指标可见性检查，即使重新计算外层哈希也不能跳过。生成创意前后及纠正请求前后重新读取已采用反馈，期间停用或更改会阻断候选返回，不自动重试、采用或修改原选中内容。

## 验收范围

可信测试父进程使用本机固定 FFmpeg/FFprobe 生成新的 lavfi 色块和正弦音轨，实际读取 VFR 解码 PTS 并保存 10 张 JPEG。应用子进程使用原隔离守卫和由仓库迁移新建的空白 SQLite/实际 Prisma；媒体适配器只重放这些经 SHA 核对的合成文件，没有给应用放开命令执行。测试不宣称复验了生产采样器的命令实现。

语义分析、创意、脚本、导演方案和使用规则结果均为进程内固定替身。实际运行原服务方法、Artifact 存储、数据库、缓存和生成器输入构造，记录实际请求内容和输出引用。采样 10 帧仅返回 8 帧观察，保留低置信文字 UNCERTAIN、缺失观察及 audio NOT_OBSERVED；三个下游请求原样保留这些限制，不额外发送媒体。

28 个子检查及父检查共 29 项：实际进程重启缓存零重复推理；源/帧/清单篡改、文件缺失、大小/MIME/状态/可变标记/路径/数据库行不符、历史无清单、重新计算分析哈希但修改 PTS；三下游的旧内存对象、停用、跨项目及缺少核验器；空/重复采样；分析和三个生成阶段期间文件变化；脚本/导演使用规则检查期间变化；自定义导演输出缺失或替换参考视频引用；U4 原始正文/父关系/计数未知；U5 明确采用的合成反馈输入回执、重哈希后的冻结证据错误、生成中停用及停用后排除。

U4/U5 使用合成作品、评论、冻结指标和明确确认的合成采用动作。这些是业务核验测试，不是新平台采集、真人采用或商业效果证据。本轮没有 HTTP/浏览器 UI 验收。

复核命令：先 `npm run build`，再 `npm run test:u2-evidence-integrity -- --ffmpeg <本机绝对路径/ffmpeg.exe> --ffprobe <本机绝对路径/ffprobe.exe>`。脚本拒绝其他参数和非绝对工具路径，只生成新的本地会话目录。原始媒体、数据库、输入和证据留在 Git 忽略的 `.runtime`，不随公开仓库发布。

首跑 Windows spawn EPERM、一次 FFmpeg 过滤表达式转义失败、一次父 ID 夹具断言失败及中途类型导入错误均保留；早期 25/25、27/27 会话与最终 29/29 分列，只有观察套件及应用进程实际退出后的 final-acceptance.json 为最终记录。CRLF 按项目现状保留。

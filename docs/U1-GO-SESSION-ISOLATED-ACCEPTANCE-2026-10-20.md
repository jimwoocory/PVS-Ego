# U1 原研究会话与 Go 执行接线隔离验收

2026-10-20。当前未提交工作区，默认执行工厂和隔离守卫未放开；本轮没有提交、推送或部署。

## 已完成的接线

`GoOwnedEgoResearchRuntime` 实现原 `EgoResearchRuntime`，显式注入原 `EgoBrowserResearchProvider`。BASIC 自有来源通过 `fetchOwnedSource` 接回原 ResearchService、Prisma、Evidence 和不可变 JSON/PNG Artifact。没有新建业务 Agent 或事实库，也没有将 Go 设为默认执行器。

Go 新增固定的 `session-open`、`session-read` 两种操作，仍只能读取配置固定的本机 nonce 页面。请求不接受网址、脚本、宿主路径、任意截图路径、控制权变更或 Space 切换指令。

会话绑定 project、research run、cycle、action、context hash、宿主实例、Default Profile、Space 名称/ID、实际页面目标 ID 与随机传输句柄。Go 进程保存原绑定，读取请求必须精确匹配；句柄是关联标识，不是浏览器授权。每次读取重新查实际 SDK 所有权和页面清单，不自动 claim、不导航到替代页、不创建替代 Space。

业务进程正常重启后可读取原研究会话与 Artifact；Go 进程失去会话表或宿主重启后不能沿旧绑定恢复权限。原 Ego 会话异常退出后的遗留锁仍需诊断，不自动删除或重新授予控制权。

## 仅采集续接

创建 BASIC 仅采集任务时，明确将 `collectionOnly` 保存到原研究状态。`resumeCollectionOnly` 只接受当前项目、原 BASIC/BLOCKED 任务、已保存标记及浏览器阻断状态；不把历史任务推断成仅采集模式，不增加来源、搜索、媒体分析、摘要或模型调用。

续接保留原 run，只补未保存来源；采用确定性的 Evidence ID 防止相同正文的并发插入重复。浏览器仍阻断时保存同一阻断和句柄，已有证据保留。全部来源采集后保持 `BRIEF_GENERATION_NOT_AUTHORIZED`，不将业务研究标记 COMPLETED。部分来源已取得时也保留后续来源的真实浏览器阻断，不因已有证据而掩盖它。

该方法及执行器仅在明确注入的隔离验收入口接线；本轮没有增加默认网页上的真实执行或续接按钮。

## 多 Space 诊断与截图

实际发现：宿主启用焦点模拟后，隐藏 Space 的 DOM 也可能返回 `visible`。因此不再把网页自己的可见性文字作为判断依据。

固定工作程序只读专用宿主的 `workspaces.json`，输出 `OWNED_HOST_LAYOUT_SNAPSHOT` 诊断。快照显示其他 Space 被选中时，必要截图在执行前以 `SPACE_HIDDEN` 阻断；由操作者选择原 Space 后明确继续，不自动切换。

**布局快照可能滞后，只用于诊断，不是实时可见性或所有权证明，更不能授予控制权。** 实时 SDK 所有权、实例和页面绑定仍单独检查，截图必须实际成功。未取得必要截图、超时或截图失败继续阻断，不能转 HTTP 或省略图片制造通过。本轮不宣称解决 Ego 全部后台截图稳定性问题。

PNG 通过固定 Go 事件传回，最多 1000000 字节；验证 PNG 签名后写入原项目受限临时目录，再由原 Provider 保存不可变 Artifact。Go stdout 行和任务事件总数仍有上限。

## 证据限制与失败保留

接管、选择和归还是可信测试包装器通过**原宿主 shell bridge 模拟的动作**。没有真人原生点击验收、真实账号登录、验证码完成或平台操作；这些仍 NOT_RUN。不得将宿主状态变化写成真实用户登录全流程通过。

第一次运行在 SDK 页面句柄尚未解析时比较目标 ID，导致 FIXTURE_BINDING_CHANGED，原失败保留；现从原 Space 页面清单按目标 ID 核对。第二次发现隐藏页的 DOM 仍报告 visible，错误测试预期失败，未将该次计为通过；改为上述有明确来源与限制的布局诊断后重新运行。中间 9/9 与最终增加部分来源用例的 10/10 分别留存，最终通过只依据观察到套件和全部子进程退出后的 `final-acceptance.json`。

此轮 Go 接线仍限定自有页面，不支持普通公开研究网址。原 U1 两条匿名公开查询属于历史限定验收，本轮未重跑。默认工厂、正式服务、原项目、Ego 源码与账号资料没有更改；没有模型、费用、素材外发、真实上传、发布、回复、生产迁移或部署。

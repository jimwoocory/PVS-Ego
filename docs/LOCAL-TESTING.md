# 本地隔离测试入口

适用范围：当前PVS-Ego独立checkout，供人工测试；不代表生产上线、完整平台E2E或GitHub正式批准。

## 启动和核对

在本仓库目录运行：

```powershell
npm run build
npm start
npm run serve
```

`npm start`应输出`ISOLATION_PREFLIGHT_ONLY`、`realExecution=DENIED`、`workers=DISABLED`和端口3097；它本身不启动服务。`serve`仅监听`127.0.0.1:3097`。服务已运行时直接打开页面，不重复启动；端口占用时不停止不明进程。保留当前终端，结束时按Ctrl+C，只关闭此测试服务。

- 工作台：[本地项目页](http://127.0.0.1:3097/projects)。
- 存活检查：[health](http://127.0.0.1:3097/health)，应为`status=ok`。
- `/health`的`baseline`是历史基线。当前版本未嵌入响应，`sourceRevision=null`且`sourceRevisionStatus=NOT_EMBEDDED_USE_CHECKOUT_GIT`；用`git rev-parse HEAD`核对当前提交，不能把基线号当作当前版本。

依赖和初始化已由当前checkout完成。需要全新副本时才按README先`npm ci --ignore-scripts`、`npm run prepare:engines`、`npm run setup`；只建立自己的新空白状态，不复制原配置、数据库、projects或浏览器账号。不要对现有数据库reset或迁移回生产配置。

首次实际Ego Lite接入需按README运行`npm run ego:configure -- --go "<绝对路径>" --ego-root "<绝对路径>"`，仅使用已安装的本机Go/Ego代码离线编译和摘要固定。本机安装清单不入Git；没有清单时采集保持拒绝。`npm run serve`会使用有效清单启动监督进程，实际宿主仍等具体动作确认后才创建。

## 人工测试顺序

以下按人工操作顺序列出；已完成范围见下节，不能把未执行项视为通过：

1. 打开项目列表，创建仅含合成名称/事实的测试项目；检查保存、返回列表和刷新后持久化。
2. 进入制作工作台与Agent工作台，检查页面、输入回显、历史记录和错误提示；仅使用本地合成内容。默认真实执行关闭，依赖模型、外部平台或缺少证据时应明确阻断，不能把阻断当成模型或平台已经执行。
3. 有保存证据时检查项目、来源、版本、文件摘要及不可核验提示；没有证据时保持未知，不显示伪造的零指标。Go专项数据位于各自的新空白测试会话，不会自动导入当前工作台。
4. 检查确认/取消与具体动作范围是否一致；未明确确认、版本过期或状态不明时应拒绝推进。不要为完成测试而放开守卫、恢复旧权限或启用后台worker。
5. 记录入口、操作、预期/实际结果、错误文字和时间；必要截图只存本地忽略目录。遇到异常保留状态，修复后按受影响的一个定向套件复验，不批量重放提交。

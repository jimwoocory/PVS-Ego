## 本地准备

需要 Node.js 22.23.2 或更新版本及 npm。运行前不需要原 PVS 目录、原数据库、原浏览器账号资料或正式配置。

```powershell
npm ci --ignore-scripts
npm run prepare:engines
npm run setup
npm run build
npm start
```

`prepare:engines` 显式调用锁定版本 Prisma 自带的引擎安装器，可能从其供应源下载平台引擎二进制，不传输项目素材。已有本平台引擎时不需要再次下载。`setup` 只使用本地引擎生成客户端，再为所有已知客户端入口加隔离守卫，创建当前目录下的全新空白会话数据库及配置。缺少本地引擎、依赖布局异常、路径为共享链接或配置不完整时停止，不回退原项目。

`npm start` 仅显示隔离预检结果。需要本地界面时显式运行：

```powershell
npm run serve
```

默认只监听 `127.0.0.1:3097`。结束时在该终端按 Ctrl+C；不注册系统服务、不操作其他端口或进程。端口冲突时先退出，不自动停止已有服务。

重复 `npm run setup` 会重建并加固客户端，保留已有数据库及配置。移动已有本地状态会被固定路径检查阻断；要换位置，复制或克隆代码后重新初始化空白状态，历史数据另行保留并单独设计迁移。

## 数据和隔离边界

- `.env`、`.pvs-isolation.json`、数据库、项目文件、浏览器资料、运行日志和原始证据均不入 Git。
- 数据库及产物目录必须属于当前 checkout 的隔离会话；禁止生产路径、相对数据库 URL、URI 查询参数、共享依赖链接与已有硬链接文件。
- 受支持的应用入口预先安装守卫：拒绝出站网络、子进程、worker、外部文件及正式执行器；只允许本机受限监听。默认禁用后台任务。
- 这是受控应用入口及 JavaScript 进程策略，不是 OS 容器、账户或防火墙沙箱，不覆盖恶意本地代码、原生扩展绕过或其他进程。
- 不要运行裸 Prisma 迁移、生成或旧生产启动脚本。依赖变更后必须重新 setup、build 并定向验证，不能跳过客户端加固。

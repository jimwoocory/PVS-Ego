# PVS-Ego

产品视频工作台的独立隔离开发与验收版本。保留产品事实、创意、脚本、导演分镜、生成授权、成片审阅、发布预检、运营数据及证据反馈的业务链。

当前默认关闭外部模型、素材外发、真实上传、付费生成、发布、评论回复和后台任务。不能将本仓库当作已获真实执行授权的生产发行版。

## 本地准备

需要 Node.js 22.23.2 或更新版本及 npm。运行前不需要原 PVS 目录、原数据库、原浏览器账号资料或正式配置。

```powershell
npm ci --ignore-scripts
npm run prepare:engines
npm run setup
npm run build
npm start
```

`prepare:engines` 显式调用锁定版本 Prisma 自带的引擎安装器，可能从其供应源下载平台引擎二进制，不传输项目素材。已有本平台引擎时不需要再次下载。`setup` 只使用本地引擎生成客户端，再为所有已知客户端入口加隔离守卫，创建当前目录下的全新空白会话数据库及配置。缺少本地引擎、依赖布局异常、路径为共享链接或配置不完整时停止，不回退原项目。

`npm start` 仅显示隔离预检结果。需要本地界面时显式运行：

```powershell
npm run serve
```

默认只监听 `127.0.0.1:3097`。结束时在该终端按 Ctrl+C；不注册系统服务、不操作其他端口或进程。端口冲突时先退出，不自动停止已有服务。

重复 `npm run setup` 会重建并加固客户端，保留已有数据库及配置。移动已有本地状态会被固定路径检查阻断；要换位置，复制或克隆代码后重新初始化空白状态，历史数据另行保留并单独设计迁移。

## 数据和隔离边界

- `.env`、`.pvs-isolation.json`、数据库、项目文件、浏览器资料、运行日志和原始证据均不入 Git。
- 数据库及产物目录必须属于当前 checkout 的隔离会话；禁止生产路径、相对数据库 URL、URI 查询参数、共享依赖链接与已有硬链接文件。
- 受支持的应用入口预先安装守卫：拒绝出站网络、子进程、worker、外部文件及正式执行器；只允许本机受限监听。默认禁用后台任务。
- 这是受控应用入口及 JavaScript 进程策略，不是 OS 容器、账户或防火墙沙箱，不覆盖恶意本地代码、原生扩展绕过或其他进程。
- 不要运行裸 Prisma 迁移、生成或旧生产启动脚本。依赖变更后必须重新 setup、build 并定向验证，不能跳过客户端加固。

## 验收

```powershell
npm test
```

当前只运行 `tests/isolation-boundary-negative.test.mjs` 一个定向套件，包含配置/传输/文件/Prisma/旧入口负例、重复初始化保护，以及复制到另一路径后的真实本地启动与 HTTP 检查。其他测试和历史验收不能自动当作本版通过记录。

本地独立化验收 **27/27**，编译退出 0；另一路径初始化和实际 `/health`、`/projects` 均返回 200。此验收使用独立物理复制的锁定依赖，**没有完成一次全新网络 npm 安装**。引擎下载与非 Windows 平台也未在本轮实测。

U2–U5 既有隔离业务 HTTP 与页面渲染验收不等于真实平台 E2E。完整浏览器点击/原生确认框取消仍未验证；U3 真实编辑态阻断保留。音频仍为不可观察。指标/评论缺失保留未知，复盘只作待验证假设，不自动采用，不把相关性当因果。真实模型、外发、付费、上传、发布、回复和生产部署必须分别取得明确授权，不承诺免验证码。

详见 [独立化验收与交付范围](docs/STANDALONE-ACCEPTANCE.md)、[架构](docs/ARCHITECTURE.md)和[第三方策略](docs/THIRD-PARTY-POLICY.md)。历史报告含本机或业务信息，完整原件保留在本地，不随公开仓库发布。
